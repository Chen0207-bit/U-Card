# 优卡 U-Card 业务系统 Demo

基于《优卡 U-Card 业务系统 PRD v1.0》的演示版：虚拟支付卡 + 多级分销 CRM + 积分商城，前后端完整业务闭环。

## 访问

- **线上**：后台 https://fc-ucard.feng85656.workers.dev/ ｜ 用户端 https://fc-ucard.feng85656.workers.dev/app
- **本地**：`node server.js` → http://localhost:5177/ 和 /app（零依赖，Node ≥ 14）

内存数据库 + 确定性种子数据（12 持卡人 / 12 卡 / 30 天交易 / 18 CRM 客户 / 10 商品 / 19 人销售组织），重启即还原。

## 三端视角（演示动线）

### 用户端 `/app`（持卡人）
选账号登录 → 卡包（卡号掩码/3D 卡面）→ USDT/法币充值 → 消费（积分抵扣+返积分）→ 任务签到 → 商城兑换（核销码）→ KYC 升级 → 邀请推广

### 后台 `/`（按身份登录，demo 免密选账号）
- **销售总监**：全局驾驶舱 + 所有模块 + **分销链路全景**（组织树/每笔交易分佣流向）
- **一级/二级销售**：自己的驾驶舱/客户/业绩/佣金 + 自己团队的分销链路
- **三级销售**：只看自己的客户/业绩/佣金
- 数据范围 = 本人 + 全部下级子树（PRD 模块1 "数据权限：全部/本部门/本人" 的落地）

## 多级分销佣金（核心演示点）

组织结构：销售总监 → 一级销售×2 → 每人二级×2 → 每人三级×3（共 18 销售 + 1 总监）

每笔充值/消费实时沿链路生成佣金（比例配置在 `core.js` 的 `COMMISSION`）：

```
客户消费 $100
  → 三级销售(直属)   +$1.00 (1%)
  → 二级销售(上级)   +$2.00 (2%)
  → 一级销售(上上级) +$0.50 (0.5%)
```

后台「分销链路」页：分佣规则卡 + 销售组织树（各级直属/分润佣金）+ 最近 10 笔交易的实时分佣链路流向图。演示时在用户端发起一笔消费，回后台刷新即可看到新链路。

## 覆盖的 PRD 模块

| PRD 模块 | Demo 覆盖 |
|---|---|
| 模块1 权限与系统管理 | 按销售身份登录 + 数据范围权限（子树可见性） |
| 模块2 U卡支付运营 | 发卡（3 等级）、冻结/调账、法币/USDT 充值、消费、退款、KYC 分级审核（限额联动）、交易流水 |
| 模块3 CRM 销售管理 | 客户 7 阶段管线、查重、跟进时间轴、业绩排行（本人直接/团队合计）、**多级佣金自动计算与结算** |
| 模块4 积分体系与商城 | 消费返分×卡等级倍率、充值奖励、签到/任务、积分抵扣、商城兑换、订单发货/核销、运营调账 |
| 模块5 用户端 H5 | 卡包、充值（USDT 二维码）、消费、任务中心、商城、订单、KYC、邀请推广 |

## 技术

```
core.js      业务核心（数据+种子+API 路由，node 与 Worker 共用, ESM）
server.js    Node 本地壳（http + 静态）
worker.js    Cloudflare Worker 壳（ASSETS + API）
public/      admin.html 后台 SPA + app.html 用户端 H5（原生 JS 单文件，无框架/CDN）
```

部署：`npx wrangler deploy`（Cloudflare Workers + static assets，内存态随 isolate 保活，冷启动自动重建种子数据）
